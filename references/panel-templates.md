# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照这里的模板念**——不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。两个模板，**默认用表格版**；他想知道某档具体意味着什么时换详细版。

所有值都从 `pool` 取，一个都不许自己编。

---

## 表格版（默认，每次起草前都用）

上半看现状，下半用来挑档。挑档提示放在最前面，**不要出现任何命令字样**。

```
难度：想改就说「项目 + 档位数字」，例如「句子 3」（也可简写成 B3）

| 项目 | 现在 | 数字越大 | 上次用的 |
|---|---|---|---|
| A 词汇 | 4 B1 全量 | 越难 | 一样 |
| B 句子 | 2 偏静 | 越容易 | 1 |
| C 衔接 | 2 常规 | 越难 | 一样 |
| D 话题 | 1 通识 | 越难 | 一样 |

可选档位（◀ = 现在）
 A 词汇  1 B1易段 · 2 易+中易 · 3 易+中易+中难 · 4 B1全量◀ · 5 +B2易段 · 6 +B2易+中易 · 7 +B2易+中难 · 8 B1+B2全量
 B 句子  0 放宽 · 1 常规 · 2 偏静◀ · 3 冷静 · 4 最静
 C 衔接  0 紧扣 · 1 偏紧 · 2 常规◀ · 3 松
 D 话题  0 兴趣内 · 1 通识◀ · 2 新领域

固定要求：250–350 词 · 目标词 4–5 个、各出现 ≥2 次且加粗 · 超纲词 ≤4% · 打算回收的旧词必须出现
```

表里「上次用的」：与「现在」相同就写 `一样`，不同就写那个数字。不同的含义是
**他调过档、但还没在任何一篇里用上**——照实说，别让他以为已经生效过了。

**B 句子是四项里唯一数字越大越容易的**（数字大 = 句子变短、小句变少）。念的时候这句别漏。

## 详细版（他问「3 档到底是什么意思」时）

结构一样，只是每档后面补上它的实际含义（`menu[项].rungs[].detail`）。

```
难度：想改就说「项目 + 档位数字」，例如「句子 3」

 A 词汇  现在 4 B1 全量 · 越大越难 · 上次一样
   1 B1易段 544词 · 2 易+中易 1088 · 3 易+中易+中难 1632 · 4 B1全量 2178◀ ·
   5 +B2易段 2802 · 6 +B2易+中易 3426 · 7 +B2易+中难 4050 · 8 B1+B2全量 4675
 B 句子  现在 2 偏静 · 越大越容易（和其他三项相反）· 上次 1
   0 放宽 句长≤24/14 小句≤5 · 1 常规 20/12 小句≤4 · 2 偏静 18/11 小句≤3◀ ·
   3 冷静 16/10 小句≤2 · 4 最静 13/8 小句≤2
 C 衔接  现在 2 常规 · 越大越难 · 上次一样
   0 紧扣 重叠≥0.07 连接词≥0.48 · 1 偏紧 ≥0.05 ≥0.40 · 2 常规 无约束◀ · 3 松 ≤0.03 ≤0.30
 D 话题  现在 1 通识 · 越大越难（没有硬闸，靠选题兑现）· 上次一样
   0 兴趣内 · 1 通识◀ · 2 新领域

固定要求（改不了）：250–350 词 · 目标词 4–5 个、各出现 ≥2 次且加粗 · 超纲词 ≤4% · 打算回收的旧词必须出现
```

## 面板用词 ↔ 字段对照（防编造；**命令只给 agent，不念给学习者**）

| 面板上写的 | 取自 |
|---|---|
| 词汇 / 句子 / 衔接 / 话题 | 就是 `menu` 的四个键名（已改成白话；底层存储字段是 `tier/syntax/cohesion/background`） |
| A / B / C / D | `menu[项].flag`：A=`--tier` · B=`--syntax` · C=`--cohesion` · D=`--background` |
| 现在 | `menu[项].current`（档名取 `rungs[].label` 里 `current: true` 那条） |
| 数字越大… | `menu[项].direction` |
| 上次用的 | `menu[项].lastUsed`；与 `current` 相同写「一样」。是否不同看 `menu[项].driftedSinceLastDraft` |
| 可选档位 / 每档含义 | `menu[项].rungs[].value` / `.label` / `.detail` |
| 固定要求 | `fixedLimits`（**五项都要，别只念一半**） |
| （**不念**） | `gateFlags` 与 `menu[项].set` —— 前者只给 passage-check，后者是给你执行用的命令 |

**他怎么回复 → 你怎么执行**：听到「句子 3」或「B3」，先核对 `menu.句子.rungs` 里 3 档存在，
再跑 `ledger axes --syntax 3`。**命令不要出现在面板里、也不要念出来**——只回一句
「好，句子调到 3（冷静）」。

## 三条硬规矩

1. **「数字越大往哪边」必须念。** 四项方向不统一——词汇/衔接/话题是越大越难，
   **句子是越大越容易，与其余三项相反**。漏念就等于给他留了读反的机会。
2. **固定要求不能省。** 那四项只是「可调的一半」，固定要求是另一半；省掉他会以为难度全能调。
3. **「上次用的」和「现在」不同时，只说明他调过档但还没用上**（v1.22.0 起体感不再自动改档），
   照实说，别说成系统自动调的。
