# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照这里的模板念**——不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。两个模板，**默认用表格**；他要挑档、或想看清全部选项时换完整菜单。

所有值都从 `pool` 取，**一个都不许自己编**（面板用词 ↔ 字段的对照见文末）。念之前先确认
`skillUpdate` 不是「落后且改了规则」那种状态。

---

## 表格版（默认，每次起草前都用）

每项一行，说清三件事：现在在哪一档、数字往大是变难还是变容易、上次那篇实际用的是哪一档。

```
| 难度项 | 现在 | 数字越大 | 上次实际用的 | 想改就发这一行 |
|---|---|---|---|---|
| 词汇 | 4/8 B1 全量 | 越难 | 一样 | axes --tier <1–8> |
| 句子 | 2/4 偏静 | 越容易 | 1 | axes --syntax <0–4> |
| 衔接 | 2/3 常规 | 越难 | 一样 | axes --cohesion <0–3> |
| 话题 | 1/2 通识 | 越难 | 一样 | axes --background <0–2> |
固定要求（改不了）：250–350 词 · 目标词 4–5 个、各出现 ≥2 次且加粗 · 超纲词 ≤4% · 打算回收的旧词必须出现
```

上面就是 2026-09-29 台账的真样。注意「句子」那行：「上次实际用的 1」和「现在 2」不一样，
说明**他调过档、但还没在任何一篇里用上** —— 照实说，别让他以为已经生效过了。

一处特别提醒：**「句子」是四项里唯一数字越大越容易的**（数字大 = 句子变短、小句变少）。
其余三项都是数字越大越难。念的时候这句别漏。

## 完整菜单（他要挑档、或问「都有什么选项」时）

把每项的**全部档位**和每档什么意思都摆出来，并标出「现在」和「上次实际用的」，附一行可复制的命令。

```
难度菜单（想改就发下面任意一行）
 词汇  现在 4/8 B1 全量      数字越大越难
   axes --tier <1–8>
   1 B1易段 544词 · 2 易+中易 1088 · 3 易+中易+中难 1632 · 4 B1全量 2178 ◀现在
   5 +B2易段 2802 · 6 +B2易+中易 3426 · 7 +B2易+中易+中难 4050 · 8 B1+B2全量 4675
 句子  现在 2/4 偏静         数字越大越容易（和其他三项相反）   上次实际用的 1
   axes --syntax <0–4>
   0 放宽 24/14 · 1 常规 20/12 · 2 偏静 18/11 ◀现在 · 3 冷静 16/10 · 4 最静 13/8
 衔接  现在 2/3 常规         数字越大越难
   axes --cohesion <0–3>
   0 紧扣 重叠≥0.07 · 1 偏紧 ≥0.05 · 2 常规 无约束 ◀现在 · 3 松 ≤0.03
 话题  现在 1/2 通识         数字越大越难（没有硬闸，靠选题兑现）
   axes --background <0–2>
   0 兴趣内 · 1 通识 ◀现在 · 2 新领域
固定要求（改不了）：250–350 词 · 目标词 4–5 个、各出现 ≥2 次且加粗 · 超纲词 ≤4% · 打算回收的旧词必须出现
```

每档后面那串短说明来自 `menu[项].rungs[].detail`（词汇给词数、句子给句长与小句数、衔接给重叠与连接词），
**原样取用，不许自己编**。

## 面板用词 ↔ 字段对照（防编造）

| 面板上写的 | 取自 |
|---|---|
| 词汇 / 句子 / 衔接 / 话题 | `menu.词汇` / `menu.句法` / `menu.语篇` / `menu.背景` |
| 现在 | `menu[项].current`（档名取 `rungs[].label` 里 `current: true` 那条） |
| 数字越大… | `menu[项].direction` |
| 上次实际用的 | `menu[项].lastUsed`；与 `current` 相同就写「一样」。是否不同看 `menu[项].driftedSinceLastDraft` |
| 想改就发这一行 | `menu[项].set` |
| 每档的短说明 | `menu[项].rungs[].detail` |
| 固定要求 | `fixedLimits`（**五项都要，别只念一半**） |
| （**不念**） | `gateFlags` —— 只给 passage-check，**不念给学习者**（念了是噪声） |

**注意：面板上四个名字是给人看的白话，`menu` 里仍是 `词汇/句法/语篇/背景`。** 别把 `句法` 念出来、
也别把 `句子` 当字段名去取。

## 三条硬规矩

1. **「数字越大往哪边」必须念。** 四项的方向不统一——词汇/衔接/话题是越大越难，
   **句子是越大越容易，与其余三项相反**。漏念就等于给他留了读反的机会。
2. **固定要求不能省。** 那四项只是「可调的一半」，固定要求是另一半；省掉他会以为难度全能调。
3. **「上次实际用的」和「现在」不同时，只说明他调过档但还没用上**（v1.22.0 起体感不再自动改档），
   照实说，别说成系统自动调的。
