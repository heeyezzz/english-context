# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照这里的模板念**——不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。两个模板，**默认用表格**；他要挑档、或想看清全部选项时换完整菜单。

所有值都从 `pool` 的输出里取，**一个都不许自己编**（填槽来源见文末）。念之前先确认
`skillUpdate` 不是 `{behind:N, ruleLayer:true}`。

---

## 表格版（默认，每次起草前都用）

```
| 轴 | 当前 | 方向 | 漂移 | 改档命令 |
|---|---|---|---|---|
| 词汇 | {词汇.current}/8 {档名} | 大=难 | {漂移} | axes --tier <1–8> |
| 句法 | {句法.current}/4 {档名} | ⚠️ 大=易（反） | {漂移} | axes --syntax <0–4> |
| 语篇 | {语篇.current}/3 {档名} | 大=难 | {漂移} | axes --cohesion <0–3> |
| 背景 | {背景.current}/2 {档名} | 大=难 | {漂移} | axes --background <0–2> |
红线：{fixedLimits 五项，用 · 连接}
```

## 完整菜单（他要挑档、或问「都有什么选项」时）

每轴列出**全部档位 + 含义**，并把「当前」与「上次成篇用过」都标出来，附可复制的 `set` 命令。

```
难度菜单（复制任一 set 去改）
 词汇 axes --tier <1–8>       当前 4 B1 全量
   1 B1易段 544词 · 2 易+中易 1088 · 3 易+中易+中难 1632 · 4 B1全量 2178 ◀当前 ·
   5 +B2易段 2802 · 6 +B2易+中易 3426 · 7 +B2易+中易+中难 4050 · 8 B1+B2全量 4675
   方向：越大越难
 句法 axes --syntax <0–4>     当前 2 偏静   ⚠️ 上次成篇用 1
   0 放宽 24/14 · 1 常规 20/12 ◀上次 · 2 偏静 18/11 ◀当前 · 3 冷静 16/10 · 4 最静 13/8
   方向：⚠️ 越大越易 —— 与其余三轴相反
 语篇 axes --cohesion <0–3>   当前 2 常规
   0 紧扣 ≥0.07 · 1 偏紧 ≥0.05 · 2 常规 无约束 ◀当前 · 3 松 ≤0.03
   方向：越大越难
 背景 axes --background <0–2> 当前 1 通识
   0 兴趣内 · 1 通识 ◀当前 · 2 新领域
   方向：越大越难（无硬闸，靠选题兑现）
红线 250–350 词 · 目标 4–5 个各≥2 次且加粗 · 超纲 ≤4% · 未申报超纲词 0 · 重逢词须出现
```

每档后面的短标签就是 `menu[轴].rungs[].detail`（词汇给词数、句法给句长/小句/被动上限、
语篇给重叠/连接词上下限），**原样取用，不许自己编**。

## 填槽来源（防编造）

| 槽位 | 取自 |
|---|---|
| 当前档 / 档名 | `menu[轴].current` / `menu[轴].rungs[].label`（`current: true` 那条） |
| 方向 | `menu[轴].direction` —— **原样念，别改写**；表格里可缩写成「大=难 / 大=易（反）」 |
| 漂移 | `menu[轴].driftedSinceLastDraft` + `.lastUsed`（真才报，报时念 lastUsed） |
| 改档命令 | `menu[轴].set` |
| 档位含义 | `menu[轴].rungs[].detail`（完整菜单用） |
| 红线 | `fixedLimits`（**五项都要，别只念一半**） |
| 硬闸参数串 | `gateFlags` —— **只给 passage-check，不念给学习者**（念了是噪声） |

## 三条硬规矩

1. **方向必须念。** 四轴的「数字方向」并不统一——词汇/语篇/背景是越大越难，**句法是越大越易，
   与其余三轴相反**。漏念方向，就等于给学习者留下把句法读反的机会。
2. **红线不能省。** 四轴只是难度契约里**可调的那半**；固定红线是另一半。省掉会让他以为难度全是可调的。
3. **漂移只可能是手动造成的。** v1.22.0 起体感不再调档，所以 `driftedSinceLastDraft` 为真
   只说明**他改过档但还没在任何成篇里用过**——照实说，别让他以为已经生效过了。
