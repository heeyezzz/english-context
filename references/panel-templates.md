# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照这里的模板念**——不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。两个模板，**默认用表格版**；他想知道某档具体意味着什么时换详细版。

所有值都从 `pool` 取，一个都不许自己编。

> **输出形态（先读这条，它决定其余一切）**：面板是**靠聊天窗口渲染的 markdown**，整块直接输出正文。
> **两道禁令**：
> 1. **不要用 ``` 围栏或 4 空格缩进包起来**——进了代码块，表格退化成学习者眼前的裸管道符
>    `| A 词汇 | 4 · B1 全量 |`，长行还会乱折。
> 2. **不要用等宽对齐排版**（`━━━` 分隔线、`│` 凑列、空格对齐、制表符画框）。聊天窗口是比例字体、
>    还会按窗口宽度折行（手机上约 40 字宽），凑好的框线一律散架成几截错位的横线。要对齐就用 markdown 表格。
> 所以下方示例前**没有**围栏，是刻意的。

**v1.36.0：四轴同向。** 句子档的索引翻转过（新 = 4 − 旧，难度包一字未动），所以现在
**四根轴一律「数字越大越难」**，面板不再需要反向警告。

---

## 表格版（默认，每次起草前都用）

三段，从上到下回答三个问题：**现在什么难度** → **每根轴能挑到哪** → **哪些改不了**。
挑档提示放在最前面，**不要出现任何命令字样**。中段只给「起点 ➔ 现在 ➔ 终点」，
完整档位表在他问的时候才展开（详细版）。

**难度：想改就说「项目 + 数字」，例如「衔接 3」（也可简写成 C3）**
**四根轴同向：数字越大越难 ↑**

| 项目 | 现在 | 可挑 | 上次用的 |
|---|---|---|---|
| A 词汇 · 词池大小 | 4 · B1 全量 | 1–8 | 一样 |
| B 句子 · 句子长短 | 1 · 冷静 | 0–4 | 一样 |
| C 衔接 · 衔接疏密 | 2 · 常规 | 0–3 | 一样 |
| D 话题 · 话题熟度 | 1 · 通识话题 | 0–2 | 一样 |

**每根轴从易到难**

| 项目 | 起点 ➔ 现在 ➔ 终点 |
|---|---|
| A 词汇 · 词池大小 | 1 B1 易段（544 词） ➔ **4 B1 全量（2178 词）现在** ➔ 8 B1+B2 全量（4675 词） |
| B 句子 · 句子长短 | 0 最静（13/8） ➔ **1 冷静（16/10）现在** ➔ 4 放宽（24/14） |
| C 衔接 · 衔接疏密 | 0 紧扣 ➔ **2 常规（无约束）现在** ➔ 3 松 |
| D 话题 · 话题熟度 | 0 兴趣内话题 ➔ **1 通识话题 现在** ➔ 2 新领域话题 |

**改不了（固定要求，五项）**

- 篇长：250–350 词
- 目标词：4–5 个，各出现 ≥2 次、至少加粗一次
- 超纲率：≤4%
- 未申报超纲词：0
- 声明的重逢词：必须至少出现一次

### 表格版的五条排版约束

1. **一行一轴，四轴四行，两张表的「项目」列逐字一致**（含「· 后的一句话定位」），让他能左右对照。
   单元格只放结论词（`4 · B1 全量` / `1–8` / `一样`），**不要把整句 `direction` 塞进单元格**。
2. **中段每轴只给三点**：`rungs` 首档、当前档（写成 `**4 B1 全量（2178 词）现在**`）、末档，
   用 ` ➔ ` 连接，括号里带该档的关键数值。**完整档位表属于详细版**，别塞回这里——
   八档全列就是这一版要修掉的可读性问题本身。
3. **「可挑」列保留**：中段只显示三点，他会想知道边界在哪。
4. **「改不了」必须五项齐全**（就是 `fixedLimits` 的五个键，括号补充留给详细版）。
   少一项他会以为难度全能调。
5. **「· 词池大小」这类一句话定位是固定文案，写死在本文件**（见下方对照表），不是 `pool` 字段，
   不许临场改写或换近义词。

**「上次用的」**：与「现在」相同写 `一样`。只要有任一轴不同，单元格写 `⚠ 3 · 调过没用上`（那个数字），
并在表格下方补一行：

> ⚠ B 句子 你上次调到了 3，但那之后的每一篇还没用上这个档位。

含义照实说：**他调过档、但还没在任何一篇里生效**（v1.22.0 起体感不再自动改档），别让他以为已经生效过。

**为什么没有「A4 · B3 · C2 · D1」这种速览串**：`B1` 和词池档名「B1 全量」撞车，
他会把它读成 CEFR 等级。要速览就读表格前两列，别自创缩写。

## 详细版（他问「3 档到底是什么意思」时）

「现在」那张表和「改不了」五项**原样保留**，只把「每根轴从易到难」那一节换成下面四张完整档位表。
「数值」列取 `rungs[].detail`（句长/小句/被动、重叠/连接词、词数）；「难度说明」列是**固定文案**，
写死在本文件、逐档照念，不许临场改写——学习者靠它形成稳定预期。**（现在）随 `current: true` 动态标注，
下面表里加粗的只是当前常用档位示例，念之前先对照 `pool` 重新加粗**。话题轴没有数值列，
就照 `menu[项].note` 说清「无硬闸，靠选题兑现」。

**A 词汇 · 词池大小**（数字越大越难：词池越大，允许出现的生僻词越多）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 1 | B1 易段 | 544 词 | 仅选取最基础、复现率最高的核心词汇 |
| 2 | B1 易+中易 | 1088 词 | 扩展至中等常用词汇范围 |
| 3 | B1 易+中易+中难 | 1632 词 | 引入较高难度的阶梯词汇 |
| 4 | B1 全量 | 2178 词 | 覆盖 B1 级别全部词汇，严格不跨级 |
| 5 | B1 全量 + B2 易段 | 2802 词 | 融入 B2 级别基础常用词汇 |
| 6 | B1 全量 + B2 易+中易 | 3426 词 | 进阶包含 B2 中等难度词汇 |
| 7 | B1 全量 + B2 易+中易+中难 | 4050 词 | 包含 B2 高阶与较难词汇 |
| 8 | B1+B2 全量 | 4675 词 | 全面开放词库，包含低频及冷僻词汇 |

**B 句子 · 句子长短**（数字越大越难：句子越长、小句越多、被动句越多）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 0 | 最静 | ≤13/8 小句≤2 被动≤0 | 极短句为主，零被动语态，无嵌套从句，顺畅易读 |
| 1 | 冷静 | ≤16/10 小句≤2 被动≤1 | 句子略有增长，严格限制被动语态使用 |
| 2 | 偏静 | ≤18/11 小句≤3 被动≤1 | 接近日常口语结构，单句可容纳多层从句/逻辑 |
| 3 | 常规 | ≤20/12 小句≤4 被动≤2 | 标准新闻媒体语篇风格，含部分复句与长句 |
| 4 | 放宽 | ≤24/14 小句≤5 被动≤4 | 开放长难句限制，阅读理解与回读成本增加 |

**C 衔接 · 衔接疏密**（数字越大越难：显性衔接越少，越要自己补关系）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 0 | 紧扣 | 重叠≥0.07 连接词≥0.48 | 逻辑衔接显性化，显式使用连词（如 because/so），极易理解 |
| 1 | 偏紧 | 重叠≥0.05 连接词≥0.4 | 逻辑连接词基本完整，偶有省略 |
| 2 | 常规 | 无约束 | 无特殊约束，遵循自然写作与表达习惯 |
| 3 | 松 | 重叠≤0.03 连接词≤0.3 | 减少显性连接词，需结合上下文隐式推导句间逻辑 |

**D 话题 · 话题熟度**（数字越大越陌生；无硬闸，靠选题兑现）

| 档 | 名称 | 难度说明 |
|---|---|---|
| 0 | 兴趣内话题 | 用户熟悉且感兴趣的领域，具备良好的背景知识基础 |
| 1 | 通识话题 | 大众熟知的社会时事或生活常识，无需补充背景知识 |
| 2 | 新领域话题 | 跨学科或陌生行业话题，需现场建立背景认知与新概念 |

固定要求（改不了）：同表格版五项，可把 `fixedLimits` 的括号补充一并给出。

## 面板用词 ↔ 字段对照（防编造；**命令只给 agent，不念给学习者**）

| 面板上写的 | 取自 |
|---|---|
| 词汇 / 句子 / 衔接 / 话题 | 就是 `menu` 的四个键名（已改成白话；底层存储字段是 `tier/syntax/cohesion/background`） |
| · 词池大小 / 句子长短 / 衔接疏密 / 话题熟度 | **固定文案**，写死在本文件，逐项挂在四个轴上；不是 `pool` 字段，不许临场改写或换近义词 |
| A / B / C / D | `menu[项].flag`：A=`--tier` · B=`--syntax` · C=`--cohesion` · D=`--background` |
| 现在 | `menu[项].current` + 该档 `rungs[].label`（档名取 `current: true` 那条） |
| 可挑 | `rungs[].value` 的首尾，写成 `首–尾`（如 1–8、0–4）。**不要**照抄 `set`——那是命令 |
| 数字越大越难 ↑ | 四轴同向（v1.36.0 起），图例只写一次、逐轴不重复。要更具体时取 `menu[项].direction` |
| 起点 ➔ 现在 ➔ 终点 | `rungs` 首档 / `current: true` 档 / 末档，各带 `label`（括号里可带 `detail` 的关键数值） |
| 上次用的 | `menu[项].lastUsed`；与 `current` 相同写「一样」，不同写 `⚠ <数字> · 调过没用上`。是否不同看 `menu[项].driftedSinceLastDraft` |
| 完整档位 / `（现在）` | `menu[项].rungs[].value` / `.label`（详细版再补 `.detail`、`.note`）；`（现在）` 标 `current: true` 那档 |
| 难度说明（详细版） | **固定文案**，写死在本文件的四张档位表里，逐档照念、不许临场改写；加粗/（现在）随 `pool` 动态标注，不认表里示例的写死位置 |
| 改不了 | `fixedLimits`（**五个键都要，别只念一半**） |
| （**不念**） | `gateFlags` 与 `menu[项].set` —— 前者只给 passage-check，后者是给你执行用的命令 |

**他怎么回复 → 你怎么执行**：听到「衔接 3」或「C3」，先核对 `menu.衔接.rungs` 里 3 档存在，
再跑 `ledger axes --cohesion 3`。**命令不要出现在面板里、也不要念出来**——只回一句
「好，衔接调到 3（松）」。**他报「B1」时是 B 轴 1 档，不是 CEFR 等级**——按轴名复述一遍再执行。

## 四条硬规矩

1. **面板是渲染出来的 markdown：不套代码块，也不用空格 / `│` / `━` 凑列对齐。** 两者都会让他看到一堆符号噪音而不是表格。
2. **「数字越大往哪边」必须念，但四轴现在同向。** v1.36.0 把句子档翻成「越大越难」，与词汇/衔接/话题一致，
   所以一句图例就够；**以后若新增反向轴，必须显式标记，不能只靠列顺序暗示**。
   （旧序是 0 常规向上越「静」，学习者按同一套直觉点菜就会读反——这正是翻转的原因。）
3. **固定要求不能省，且要五项齐全。** 可调的四轴只是一半，固定要求是另一半；
   措辞要从 `fixedLimits` 取——「重逢词」是他**这篇申报要回收**的旧词，不是笼统的「上次没回收的词」。
4. **「上次用的」和「现在」不同时，只说明他调过档但还没用上**（v1.22.0 起体感不再自动改档），
   照实说，别说成系统自动调的。
