# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照本模板念**，不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。面板只有一个版本：六张完整档位表 + 「固定配置参数」四项。
挑档的交互方式（说「项目 + 数字」）由 agent 口头带一句，不占面板版面。

所有数值都从 `pool` 取，一个都不许自己编。

> **输出形态（先读这条，它决定其余一切）**：面板是**靠聊天窗口渲染的 markdown**，整块直接输出正文。
> **两道禁令**：
> 1. **不要用 ``` 围栏或 4 空格缩进包起来**——进了代码块，表格退化成学习者眼前的裸管道符，
>    长行还会乱折。
> 2. **不要用等宽对齐排版**（`━━━` 分隔线、`│` 凑列、空格对齐、制表符画框）。聊天窗口是比例字体、
>    还会按窗口宽度折行（手机上约 40 字宽），凑好的框线一律散架。要对齐就用 markdown 表格。

## 面板（从上到下，一段都不能省）

**A 词汇 · 词池大小**（词池越大，允许出现的生僻词越多）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 1 | B1 易段 | 544 词 | 仅选取最基础、复现率最高的核心词汇 |
| 2 | B1 易+中易 | 1088 词 | 扩展至中等常用词汇范围 |
| 3 | B1 易+中易+中难 | 1632 词 | 引入较高难度的阶梯词汇 |
| 4 | B1 全量 | 2178 词 | 覆盖 B1 级别全部词汇，严格不跨级 |
| 5 | B1 全量 + B2 易段 | 2802 词 | 融入 B2 级别基础常用词汇 |
| 6 | B1 全量 + B2 易+中易 | 3426 词 | 进阶包含 B2 中等难度词汇 |
| 7 | B1 全量 + B2 易+中易+中难 | 4050 词 | 包含 B2 高阶与较难词汇 |
| 8 | B1+B2 全量 | 4675 词 | 全面开放词库，包含低频及冷僻词汇 |

**B 句子 · 句子长短**（句子越长、小句越多、被动句越多）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 0 | 最静 | ≤13/8 小句≤2 被动≤0 | 极短句为主，零被动语态，无嵌套从句，顺畅易读 |
| 1 | 冷静 | ≤16/10 小句≤2 被动≤1 | 句子略有增长，严格限制被动语态使用 |
| 2 | 偏静 | ≤18/11 小句≤3 被动≤1 | 接近日常口语结构，单句可容纳多层从句/逻辑 |
| 3 | 常规 | ≤20/12 小句≤4 被动≤2 | 标准新闻媒体语篇风格，含部分复句与长句 |
| 4 | 放宽 | ≤24/14 小句≤5 被动≤4 | 开放长难句限制，阅读理解与回读成本增加 |

**C 衔接 · 衔接疏密**（显性衔接越少，越要自己补关系）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 0 | 紧扣 | 重叠≥0.07 连接词≥0.48 | 逻辑衔接显性化，显式使用连词（如 because/so），极易理解 |
| 1 | 偏紧 | 重叠≥0.05 连接词≥0.4 | 逻辑连接词基本完整，偶有省略 |
| 2 | 常规 | 无约束 | 无特殊约束，遵循自然写作与表达习惯 |
| 3 | 松 | 重叠≤0.03 连接词≤0.3 | 减少显性连接词，需结合上下文隐式推导句间逻辑 |

**D 话题 · 话题熟度**（越陌生越难；无硬闸，靠选题兑现，脚本量不到）

| 档 | 名称 | 难度说明 |
|---|---|---|
| 0 | 兴趣内话题 | 用户熟悉且感兴趣的领域，具备良好的背景知识基础 |
| 1 | 通识话题 | 大众熟知的社会时事或生活常识，无需补充背景知识 |
| 2 | 新领域话题 | 跨学科或陌生行业话题，需现场建立背景认知与新概念 |

**E 底词 · 底词宽窄**（选哪档，背景词就只能从那个带里挑；v1.48.0 起不限数量）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 1 | A2 底 | 背景零超纲 | 除目标词外全部 A2 以下或已知——只有那 4–5 个目标词是新的（默认，即旧行为） |
| 2 | B1 易段 | 背景可选 544 词 | 背景词只能从最基础一档的 B1 词里出现，不注释、不记账 |
| 3 | B1 易+中易 | 背景可选 1088 词 | 背景可及的 B1 词变宽 |
| 4 | B1 易+中易+中难 | 背景可选 1632 词 | 中难 B1 词开始进背景 |
| 5 | B1 全量 | 背景可选 2178 词 | B1 全级可作背景 |
| 6 | B1 全量 + B2 易段 | 背景可选 2802 词 | B2 易词进背景，陌生感明显上升 |
| 7 | B1 全量 + B2 易+中易 | 背景可选 3426 词 | B2 中易词可作背景 |
| 8 | B1 全量 + B2 易+中易+中难 | 背景可选 4050 词 | 背景顶格（B2 全量仍是目标词的领地）；混多少不封顶，读感由你按体感回调 |

> 底词档的背景词**不加粗、不注释、不进曝光台账**——纯混脸熟。软提醒：底词档一般 ≤ 词汇档−1，
> 越界等于背景比目标词还难，设计上是反的（不拦，照实念这句）。

**F 篇长 · 整篇字数**（v1.53.0：数字越大篇越长，目标词个数同步联动；默认档 1 = 旧行为）

| 档 | 名称 | 数值 | 难度说明 |
|---|---|---|---|
| 0 | 超短 | 180–250 词 · 目标词 3–4 | 三分钟读完一篇，通勤碎片时间；目标词降到 3–4 个——短篇塞 5 个会顶穿超纲率 4% 的额度 |
| 1 | 标准 | 250–350 词 · 目标词 4–5 | 现状区间（默认，即旧行为） |
| 2 | 中等 | 350–550 词 · 目标词 4–5 | 多给情节与语境铺展，词数压力不变 |
| 3 | 长 | 550–850 词 · 目标词 5–6 | 一篇顶过去两篇，目标词微增，仍按 4% 率闸走 |
| 4 | 超长 | 850–1200 词 · 目标词 6–8 | 准章节体量；单程通勤读不完的风险自己拿 |

**固定配置参数**

- 目标词：个数随篇长档联动（见 F 表），各出现 ≥2 次、至少加粗一次
- 超纲率：≤4%
- 未申报超纲词：底词 1 档为 0；底词 ≥2 档时背景词只能从所选带里挑，不限数量（见 E 表）
- 声明的重逢词：必须至少出现一次

### 念之前必做的两处动态处理

1. **`（现在）` 随 `pool` 动态标注**：给每轴 `current: true` 的那档加 `** …（现在）**` 加粗。
   上面表里没写（现在）、也没预置加粗档位——**表里出现任何示例位置都不可信，照 pool 重新标**。
2. **漂移提醒行（仅当任一轴 `driftedSinceLastDraft` 为 true——即 `lastUsed` 与 `current` 不一致——加在表格下方）**：

   > ⚠ B 句子 你上次调到了 3，但那之后的每一篇还没用上这个档位。

   含义照实说：**他调过档、但还没在任何一篇里生效**（v1.22.0 起体感不再自动改档），
   别让他以为已经生效过，也别说是系统自动调的。

## 模板用词 ↔ 字段对照（防编造；**命令只给 agent，不念给学习者**）

| 面板上写的 | 取自 |
|---|---|
| 词汇 / 句子 / 衔接 / 话题 / 底词 | 就是 `menu` 的五个键名（底层存储字段是 `tier/syntax/cohesion/background/baseword`） |
| 轴名括号里的方向句（如「词池越大，允许出现的生僻词越多」） | 从 `menu[项].direction`（「数字越大越难（…）」）压缩而来，方向不许念反 |
| · 词池大小 / 句子长短 / 衔接疏密 / 话题熟度 / 底词宽窄 | **固定文案**，写死在本文件，逐项挂在五个轴上；不是 `pool` 字段，不许临场改写或换近义词 |
| A / B / C / D / E | `menu[项].flag`：A=`--tier` · B=`--syntax` · C=`--cohesion` · D=`--background` · E=`--baseword` |
| 档 / 名称 | `menu[项].rungs[].value` / `.label`——名称列**逐字照 label**，不许简写（`B1` 会和 CEFR 等级撞车） |
| 数值 | `menu[项].rungs[].detail`（句长两数字 = 单句上限/平均上限）；话题轴无此列 |
| 难度说明 | **固定文案**，写死在本文件，逐档照念，不许临场改写——学习者靠它形成稳定预期 |
| （现在） | `rungs[]` 里 `current: true` 那档 |
| 固定配置参数 | `fixedLimits` 的**五个键全念，别只念一半**；「重逢词」是他**这篇申报要回收**的旧词，不是笼统的「上次没回收的词」 |
| （**不念**） | `gateFlags` 与 `menu[项].set`——前者只给 passage-check，后者是给你执行用的命令 |

**他怎么回复 → 你怎么执行**：听到「衔接 3」或「C3」，先核对 `menu.衔接.rungs` 里 3 档存在，
再跑 `ledger axes --cohesion 3`。**命令不要出现在面板里、也不要念出来**——只回一句
「好，衔接调到 3（松）」。**他报「B1」时是 B 轴 1 档，不是 CEFR 等级**——按轴名复述一遍再执行。

## 四条硬规矩

1. **面板是渲染出来的 markdown：不套代码块，也不用空格 / `│` / `━` 凑列对齐。**
2. **方向靠每轴标题的括号句承载**（五轴同向、数字越大越难，v1.36.0 起四轴同向、v1.47.0 底词沿用同约定；v1.53.0 的 F 篇长例外——数字越大篇越长，目标词个数随之联动。面板不再单列图例行）。
   以后若新增反向轴，必须在其标题显式标记，不能只靠列顺序暗示。
3. **「固定配置参数」四项齐全**：可调的六轴只是一半，固定配置参数是另一半，措辞从 `fixedLimits` 取。
4. **档位名、数值、难度说明三者不许串位或即兴**：前两列照 `pool`，第三列照本文件；
   唯一的动态处理是 `（现在）` 与漂移提醒行。
