# 生成前的难度面板 · 固定模板（模板级规则 ④）

起草前把难度面板念给学习者时，**照这里的模板念**——不要临时组织格式（每个 agent 念得都不一样，
学习者就无法形成稳定预期）。两个模板，**默认用表格版**；他想知道某档具体意味着什么时换详细版。

所有值都从 `pool` 取，一个都不许自己编。

> **输出形态（先读这条，它决定其余一切）**：面板是**靠聊天窗口渲染的 markdown**，整块直接输出正文。
> **两道禁令**：
> 1. **不要用 ``` 围栏或 4 空格缩进包起来**——进了代码块，表格退化成学习者眼前的裸管道符
>    `| A 词汇 | 4 · B1 全量 |`，长行还会乱折。
> 2. **不要用等宽对齐排版**（`1 级 (544词)   │ 2 级 (1088词)`、空格凑列、制表符画框）。
>    聊天窗口是比例字体、还会按窗口宽度折行，凑好的列一律对不齐。要对齐就用 markdown 表格，让渲染器去对齐。
> 所以下方示例前**没有**围栏，是刻意的。

---

## 表格版（默认，每次起草前都用）

从上到下回答三个问题：**现在什么难度** → **能挑哪些档** → **哪些改不了**。
挑档提示放在最前面，**不要出现任何命令字样**。

**难度：想改就说「项目 + 数字」，例如「句子 3」（也可简写成 B3）**
**趋势：↑ = 数字越大越难 · ↓ = 数字越大越容易**

| 项目 | 现在 | 可挑 | 趋势 | 上次用的 |
|---|---|---|---|---|
| A 词汇【词池大小】 | 4 · B1 全量 | 1–8 | ↑ 越难 | 一样 |
| **B 句子【句子长短】** | **3 · 冷静** | 0–4 | **⚠ ↓ 越容易** | 一样 |
| C 衔接【句子接得紧不紧】 | 2 · 常规 | 0–3 | ↑ 越难 | 一样 |
| D 话题【话题熟不熟】 | 1 · 通识话题 | 0–2 | ↑ 越难 | 一样 |

**每档是什么**

| 项目 | 档位（数字从小到大，`[已选]` = 现在） |
|---|---|
| A 词汇【词池大小】 | 1 B1 易段 · 2 B1 易+中易 · 3 B1 易+中易+中难 · **4 B1 全量 [已选]** · 5 B1 全量 + B2 易段 · 6 B1 全量 + B2 易+中易 · 7 B1 全量 + B2 易+中易+中难 · 8 B1+B2 全量 |
| **B 句子【句子长短】** | **⚠ 越大越容易** · 0 放宽 · 1 常规 · 2 偏静 · **3 冷静 [已选]** · 4 最静 |
| C 衔接【句子接得紧不紧】 | 0 紧扣 · 1 偏紧 · **2 常规 [已选]** · 3 松 |
| D 话题【话题熟不熟】 | 0 兴趣内话题 · **1 通识话题 [已选]** · 2 新领域话题 |

**改不了（固定要求，五项）**

- 篇长：250–350 词
- 目标词：4–5 个，各出现 ≥2 次、至少加粗一次
- 超纲率：≤4%
- 未申报超纲词：0
- 声明的重逢词：必须至少出现一次

### 表格版的四条排版约束

1. **一行一轴，四轴四行**。「现在」「可挑」「趋势」「上次用的」各占一列，单元格只放结论词
   （`4 · B1 全量` / `1–8` / `↑ 越难`），**不要把整句 `direction` 塞进单元格**——完整方向句留给详细版。
2. **档位表一轴一行**，「项目」列与上表逐字一致（含【】定位）；第二列按 `rungs[].value` 从小到大
   列全该轴所有档，用 `rungs[].label` 原文、` · ` 分隔、当前档写成 `**4 B1 全量 [已选]**`，
   B 句子行整行加粗并在行首带 `⚠ 越大越容易`。
   单元格内自然折行是**预期**的；**不要**把档位拆成一档一列（8 列会把表格撑出横向滚动），
   也不要包进代码块或用 `│` 凑列。
3. **「改不了」必须五项齐全**（就是 `fixedLimits` 的五个键，括号补充留给详细版）。
   少一项他会以为难度全能调。
4. **四个【】短语是固定文案，写死在本文件里**（见下方对照表）。它们是给学习者的一句话定位，
   **不是** `pool` 的字段，也不许每次临场重写。

**「上次用的」**：与「现在」相同写 `一样`。只要有任一轴不同，单元格写 `⚠ 1 · 调过没用上`（那个数字），
并在表格下方补一行：

> ⚠ B 句子 你上次调到了 1，但那之后的每一篇还没用上这个档位。

含义照实说：**他调过档、但还没在任何一篇里生效**（v1.22.0 起体感不再自动改档），别让他以为已经生效过。

**B 句子是四项里唯一数字越大越容易的**（数字大 = 句子变短、小句越少），所以整行加粗、趋势带 ⚠。
念的时候这句别漏。

## 详细版（他问「3 档到底是什么意思」时）

「现在」那张表和「改不了」五项**原样保留**，只把「每档是什么」那一节换成下面四张小表：
每个档名后面补 `rungs[].detail`（词数、句长/小句/被动、重叠/连接词），轴名后的括号用 `direction` 完整句。
话题轴没有 detail，就照 `menu[项].note` 说清「无硬闸，靠选题兑现」。

**A 词汇**（数字越大越难：词池越大，允许出现的生僻词越多）

| 档 | 名称 | 词池 |
|---|---|---|
| 1 | B1 易段 | 544 词 |
| 2 | B1 易+中易 | 1088 词 |
| 3 | B1 易+中易+中难 | 1632 词 |
| **4** | **B1 全量 [已选]** | **2178 词** |
| 5 | B1 全量 + B2 易段 | 2802 词 |
| 6 | B1 全量 + B2 易+中易 | 3426 词 |
| 7 | B1 全量 + B2 易+中易+中难 | 4050 词 |
| 8 | B1+B2 全量 | 4675 词 |

**B 句子**（⚠ 数字越大越「容易」：句子越短、小句越少——与其他三轴相反）

| 档 | 名称 | 闸门 |
|---|---|---|
| 0 | 放宽 | 句长≤24/14 小句≤5 被动≤4 |
| 1 | 常规 | 句长≤20/12 小句≤4 被动≤2 |
| 2 | 偏静 | 句长≤18/11 小句≤3 被动≤1 |
| **3** | **冷静 [已选]** | **句长≤16/10 小句≤2 被动≤1** |
| 4 | 最静 | 句长≤13/8 小句≤2 被动≤0 |

**C 衔接**（数字越大越难：衔接越少，越要自己补关系）

| 档 | 名称 | 闸门 |
|---|---|---|
| 0 | 紧扣 | 重叠≥0.07 连接词≥0.48 |
| 1 | 偏紧 | 重叠≥0.05 连接词≥0.4 |
| **2** | **常规 [已选]** | **无约束** |
| 3 | 松 | 重叠≤0.03 连接词≤0.3 |

**D 话题**（数字越大越陌生；无硬闸，靠选题兑现）

| 档 | 名称 |
|---|---|
| 0 | 兴趣内话题 |
| **1** | **通识话题 [已选]** |
| 2 | 新领域话题 |

固定要求（改不了）：同表格版五项，可把 `fixedLimits` 的括号补充一并给出。

## 面板用词 ↔ 字段对照（防编造；**命令只给 agent，不念给学习者**）

| 面板上写的 | 取自 |
|---|---|
| 词汇 / 句子 / 衔接 / 话题 | 就是 `menu` 的四个键名（已改成白话；底层存储字段是 `tier/syntax/cohesion/background`） |
| 【词池大小】【句子长短】【句子接得紧不紧】【话题熟不熟】 | **固定文案**，写死在本文件，逐项挂在四个轴上；不是 `pool` 字段，不许临场改写或换近义词 |
| A / B / C / D | `menu[项].flag`：A=`--tier` · B=`--syntax` · C=`--cohesion` · D=`--background` |
| 现在 | `menu[项].current` + 该档 `rungs[].label`（档名取 `current: true` 那条） |
| 可挑 | `rungs[].value` 的首尾，写成 `首–尾`（如 1–8、0–4）。**不要**照抄 `set`——那是命令 |
| ↑ 越难 / ⚠ ↓ 越容易 | `menu[项].direction` 的核心结论 + 方向；完整句只用于详细版轴名后的括号 |
| 趋势那一行的图例 | 固定文案 `↑ = 数字越大越难 · ↓ = 数字越大越容易`，只写一次，不逐轴重复解释 |
| 上次用的 | `menu[项].lastUsed`；与 `current` 相同写「一样」，不同写 `⚠ <数字> · 调过没用上`。是否不同看 `menu[项].driftedSinceLastDraft` |
| 每档是什么 / `[已选]` | `menu[项].rungs[].value` / `.label`（详细版再补 `.detail`、`.note`）；`[已选]` 标 `current: true` 那档 |
| 改不了 | `fixedLimits`（**五个键都要，别只念一半**） |
| （**不念**） | `gateFlags` 与 `menu[项].set` —— 前者只给 passage-check，后者是给你执行用的命令 |

**他怎么回复 → 你怎么执行**：听到「句子 3」或「B3」，先核对 `menu.句子.rungs` 里 3 档存在，
再跑 `ledger axes --syntax 3`。**命令不要出现在面板里、也不要念出来**——只回一句
「好，句子调到 3（冷静）」。

## 四条硬规矩

1. **面板是渲染出来的 markdown：不套代码块，也不用空格/│ 凑列对齐。** 两者都会让他看到一堆符号噪音而不是表格。
2. **「数字越大往哪边」必须念。** 四项方向不统一——词汇/衔接/话题是越大越难（↑），
   **句子是越大越容易（↓），与其余三项相反**，所以带 ⚠ 且整行加粗。漏念就等于给他留了读反的机会。
3. **固定要求不能省，且要五项齐全。** 可调的四轴只是一半，固定要求是另一半；
   措辞要从 `fixedLimits` 取——「重逢词」是他**这篇申报要回收**的旧词，不是笼统的「上次没回收的词」。
4. **「上次用的」和「现在」不同时，只说明他调过档但还没用上**（v1.22.0 起体感不再自动改档），
   照实说，别说成系统自动调的。
